# Daniel Molloy — brand pack

Everything here is generated by `npm run brand` from `lib/brand.ts` and
`scripts/generate-brand-assets.mjs`. **Do not edit these files by hand** — the next
regeneration overwrites them. Change the source and re-run.

## The mark

A "DM" monogram in Inter SemiBold, knocked out of a charcoal rounded square. The
corner radius is 22% of the square (7 units on a 32-unit grid). The monogram is
centred on its ink bounding box, not on advance widths — centring on advances leaves
it visibly off to one side.

Letterforms in every shipped file are **outlined vector paths**, not text. Nothing
references a font by name, so the mark renders identically on macOS, Windows, Android
and in server-side rasterisers. Any file here containing `<text>` or `font-family` is
a bug; the generator fails the build if one appears.

## Colour

Brand colour is derived from the theme tokens in `app/globals.css`, so assets and the
rendered site always match.

| Role | Hex | oklch | CSS token |
|---|---|---|---|
| Ink — the mark's field, headings | `#0d0a0b` | `oklch(0.15 0.005 0)` | `--foreground` |
| Surface — letterforms, backgrounds | `#faf8f5` | `oklch(0.98 0.005 85)` | `--background` |
| Muted — supporting copy | `#585455` | `oklch(0.45 0.005 0)` | `--muted-foreground` |
| Accent — deep graphite blue, used sparingly | `#313c44` | `oklch(0.35 0.02 240)` | `--accent` |

Earlier assets used `#1a1a1a` and `#f5f0e8`. Those are superseded — they were close
to, but not the same as, the colours the site actually rendered, so the OG card never
quite matched the page it linked to.

## Typography

Inter throughout, loaded via `next/font/google`. The monogram is SemiBold (600); the
wordmark's name is Medium (500). There is no secondary typeface.

## Clear space and minimum sizes

- **Clear space:** keep free space on all sides equal to the mark's corner radius —
  22% of its height. Nothing else sits inside that margin.
- **Mark minimum:** 16px. Below that the monogram fills in and stops reading.
- **Wordmark minimum:** 140px wide.
- Do not recolour, outline, add effects to, stretch, or rotate the mark. Do not
  reconstruct the monogram by setting "DM" in a font — use these files.

## Which file to use

| Need | File |
|---|---|
| Anywhere vector works | `mark.svg` |
| Mark plus the name, light background | `wordmark.svg` |
| Mark plus the name, dark background | `wordmark-reverse.svg` |
| Raster icon, any size | `icon-{16,32,48,64,128,180,192,256,512,1024}.png` |
| Android home screen | `icon-maskable-512.png` |
| LinkedIn, X, GitHub profile picture | `avatar-{400,800,1024}.png` |

Rounded PNGs have transparent corners. Maskable and avatar files are full-bleed with
the monogram pulled into the centre 80%, so circular and squircle crops never clip it.

In the app itself the nav and footer use `components/brand/logo.tsx`, which renders
the mark as inline SVG with live Inter text beside it — the webfont is already loaded
there, and live text stays selectable and searchable. The outlined `wordmark.svg` is
for recipients who do not have Inter.
